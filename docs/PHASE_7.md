# Phase 7 — Controlled Self-Improvement

## Loop

OBSERVE → PROPOSE (evidence required) → EXPERIMENT (shadow) → EVALUATE → APPROVE → STAGE → CANARY → PROMOTE | ROLLBACK → LEARN

## Hard boundaries

No self-approval. No auto-change of auth/tenant/secrets/governance/evaluation disablement.
Change freeze + emergency stop halt autonomous deployment.

## Risk levels

LEVEL_0–1 may auto-approve under policy. LEVEL_2+ human. LEVEL_4 critical requires elevated role.
